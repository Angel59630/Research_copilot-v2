# 问答前端模块设计

## 1. 职责

提供单论文与分组多会话、会话级模型选择、SSE 流式回答、中止、富文本渲染、上下文压缩和 Markdown 导出。

## 2. 布局

使用桌面双栏布局：

- 左栏：会话列表、新建、重命名和删除。
- 主区：消息列表、模型选择、输入框、生成控制和压缩操作。

不包含 PDF 阅读区域。

## 3. 会话能力

- 每篇论文或每个分组可有多个会话。
- 模型列表由后端读取 `config.py` 后动态返回。
- 模型切换只影响后续回答。
- 支持复制回答和重新生成上一条回答。
- 支持删除会话。
- 支持导出 UTF-8 Markdown。

## 4. SSE

- 处理内容增量、完成、错误和中止事件。
- 生成期间允许用户中止。
- 网络或模型错误展示 `request_id`。
- 不把残缺回答当作正式历史渲染。
- 不使用 WebSocket。

## 5. 富文本与引用

- 支持 Markdown、代码高亮、表格和 LaTeX。
- 过滤不可信 HTML 和脚本。
- 引用只展示论文名称和 PDF 物理页码。
- 引用不可点击，不提供 PDF 定位。

## 6. 上下文压缩

- 提供手动压缩按钮和当前压缩状态。
- 自动压缩由后端判断，前端只展示进行中、完成或失败状态。
- 压缩不隐藏或删除原始历史消息。
