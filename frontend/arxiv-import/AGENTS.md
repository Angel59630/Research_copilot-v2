# Arxiv 导入前端模块设计

## 1. 职责

提供 Arxiv 论文搜索、结果浏览、选择导入和 Arxiv ID 或链接直接导入界面。

## 2. 页面能力

- 按关键词、标题或作者搜索。
- 结果分页与排序。
- 显示标题、作者、摘要、发表日期和分类。
- 选择一篇或多篇结果导入。
- 输入 Arxiv ID 或链接直接导入。
- 导入成功后跳转或链接到论文库任务状态。
- 展示必要的 Arxiv 数据来源致谢。

## 3. 交互规则

- 搜索请求支持取消和防重复提交。
- 导入按钮只表示创建导入任务，不等待解析和向量化完成。
- 即使相同论文已存在，也允许再次导入为独立记录。
- 错误显示中文摘要和 `request_id`。

## 4. 边界

- 浏览器不直接访问 Arxiv 或 MCP。
- 不在前端下载或保存 PDF。
- 不进行客户端去重。
