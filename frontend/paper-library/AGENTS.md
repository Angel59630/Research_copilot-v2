# 论文库前端模块设计

## 1. 职责

论文库界面负责本地 PDF 上传、论文分页列表、标题与作者搜索、状态筛选、元数据编辑、PDF 下载、永久删除确认和导入状态展示。

## 2. 数据流

```text
LibraryView / PaperUpload
→ src/stores/papers.ts
→ src/api/papers.ts
→ src/api/client.ts
→ FastAPI 论文与导入接口
```

- 上传按钮通过隐藏文件输入框的组件引用显式触发文件选择，不得依赖 `label` 的隐式点击行为。
- 上传成功仅表示论文进入队列，随后重新加载列表。
- 存在 `queued`、`parsing` 或 `embedding` 论文时，每三秒进行一次非重叠轮询。
- 全部论文进入终态后停止轮询，页面卸载时也必须清理定时器。
- 编辑前读取论文详情，保存后使用后端返回记录更新列表。
- 删除必须二次确认，收到成功响应后重新加载当前分页。

## 3. 错误与状态

- 健康检查失败时显示后端不可用提示。
- 请求错误通过统一客户端转换为中文消息，并在可用时显示 `request_id`。
- 处理失败原因只显示后端提供的安全错误摘要。
- 下载使用论文 ID 获取 Blob，文件名使用后端论文记录中的安全文件名。

## 4. 边界

- 不实现 PDF 内嵌阅读、页码点击跳转或原文高亮。
- 不在前端推断处理完成，后端状态是唯一事实来源。
- 不直接拼接本地文件路径或访问项目数据目录。
