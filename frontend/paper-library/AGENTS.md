# 论文库前端模块设计

## 1. 职责

提供论文上传、分页列表、搜索筛选、处理状态、元数据编辑、标签、下载、重试、分组关系入口和永久删除界面。

## 2. 页面能力

- 上传单个或多个本地 PDF。
- 按标题、作者和标签搜索。
- 按分组、未分类、状态和来源筛选。
- 显示等待、解析、向量化、完成、失败和已中断状态。
- 编辑标题、作者、发表日期、摘要、标签和备注。
- 下载原始 PDF。
- 对失败或中断任务发起重试。
- 打开单论文问答。
- 二次确认后删除论文。

## 3. 状态更新

后台任务状态通过轻量轮询或统一状态查询刷新，不为任务进度单独引入 WebSocket。失败提示展示安全原因和 `request_id`。

## 4. 边界

- 不读取 PDF 内容，不提供内置阅读器。
- 不在前端解析、分块或生成向量。
- 不执行论文去重。
- 不实现独立 AI 摘要功能。
