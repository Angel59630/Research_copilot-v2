# 分组模块设计

## 1. 职责

分组模块拥有一级普通分组和论文分组关系，提供分组管理、成员维护和“未分类”虚拟视图。

## 2. 数据模型

- `Group`：内部 ID、名称、创建时间、更新时间。
- `PaperGroup`：论文与普通分组的多对多关系。
- “未分类”不是数据库实体。

## 3. 规则

- 只允许一级分组，不存在父子关系。
- 同一论文可属于多个普通分组。
- 未加入任何普通分组的论文由查询实时归入“未分类”。
- 论文加入普通分组后不再显示在“未分类”。
- 删除全部所属分组后自动重新显示在“未分类”。
- “未分类”不能重命名或删除。

## 4. 公开能力

- 创建、重命名、分页查询和删除普通分组。
- 批量添加或移除论文成员。
- 查询分组当前可用于问答的论文 ID 集合。
- 查询“未分类”论文。
- 删除分组前返回受影响的分组会话数量。

## 5. 删除协调

删除普通分组时：

1. 由会话模块删除该分组的全部问答会话。
2. 删除论文分组关系。
3. 删除分组记录。
4. 不删除任何论文或单论文会话。

## 6. 边界

- 不复制 PDF 或向量数据。
- 不保存分组问答范围快照。
- 分组问答每次使用当前成员。
